# 规则 vs LLM（DeepSeek）对比结论

> 日期：2026-09-03 ｜ 数据：本机实跑（DeepSeek，200 条全量 + 60 条样本）
> 原始报告：docs/eval_reports/llm_vs_rule_latest.json

## 1. 数字结果

| 数据集 | 规则 | LLM | LLM 平均耗时 |
|---|---|---|---|
| 60 条样本 | 96.7% | 93.3% | 1.37s/次 |
| 200 条全量 | 99.0%（198/200） | 94.0%（188/200） | 1.34s/次 |

表面结论：规则在这个数据集上比 LLM 高 5 个点，且 LLM 慢（1.3s vs <1ms）、有成本。

## 2. 关键提醒：这个对比对 LLM 并不公平

golden set 是**按规则关键词构造并标注**的（比如“含‘订单’二字归 order、含‘退’归 refund”），
规则引擎等于在“自己出的卷子”上考试；LLM 按语义理解作答，遇到两类题会“吃亏”：

- **标注口径偏规则**：如“退货规则是什么”“运费险怎么用”“支持微信支付吗”——
  人工语义上更像“知识库/规则咨询（knowledge）”，但 golden 按关键词标成 refund/fallback/order；
- **规则先验的上下文题**：如“订单预计什么时候配送”语义是物流，但 golden 因关键词“订单”标成 order。

因此 99.0% vs 94.0% 的正确解读是：
**“在关键词构造的评测集上规则更匹配”，不代表“规则比 LLM 更聪明”。**

## 4. 生产建议（混合路由，而不是二选一）

**推荐策略：规则为主、LLM 兜底低置信度/难例。**

```text
输入 → 规则分类（<1ms，0 成本）
   ├─ 高置信且命中关键词 → 直接采用（覆盖 ~95% 日常）
   ├─ 命中“口语难例白名单/低置信度”（如含“还没到/坏了/修/配送时间”） → 交给 LLM 二次判定
   └─ 规则与 LLM 不一致且都拿不准 → 转人工（保守策略）
```

- 收益：日常请求保持 99% 准确 + 毫秒级 + 零 token 成本；
- LLM 只处理真正需要语义判断的少量请求（预计 <10%），单次成本可忽略；
- 把 #53 这类规则漏判的难例收进“LLM-only”清单，规则引擎反而能借 LLM 补上最后几个点。

## 5. 独立人工语义验证集（公平卷）结果

为避免“规则在自己出的卷子上考试”，新增 docs/independent_golden.json（40 条，按语义不按关键词标注）：

| 指标 | 规则 | LLM（DeepSeek） |
|---|---|---|
| 总体 | 30/40 = **75.0%** | 37/40 = **92.5%** |
| 订单查询 | 5/7 | 7/7 |
| 物流查询 | 4/7 | 7/7 |
| 退换货/退款 | 6/7 | 6/7 |
| 投诉/转人工 | 6/6 | 5/6 |
| 知识库查询 | 3/7 | 6/7 |
| 其他 | 6/6 | 6/6 |

LLM 三处漏判：#I15“东西坏了能修吗”（判知识库，售后语义可争议）、#I25“客服电话”（业务上应转人工，判 fallback）、
#I29“运费险怎么用”（判退款，语义可争议）。

结论修正：**在语义/口语题上 LLM 明显更强（+17.5 点）**；规则的优势只在“关键词高度匹配”的语料（99%）。
这坐实了混合路由的必要性：谁也别想只靠一套赢。

## 7. 语义口径 200 条终版（混合路由实测）

把 200 条 golden 中 6 条歧义题改为语义口径后（docs/golden_set.json v3），三路实测：

| 方案 | 200 条语义口径 | LLM 调用 | 40 条独立语义集 |
|---|---|---|---|
| 规则 | 96.0% | 0 | 75.0% |
| 纯 LLM | 96.5% | 200（100%） | 92.5% |
| **混合路由** | **99.0%** | **46（23%）** | **97.5%** |

混合路由在两份卷子上都是最高分，LLM 调用只占约 1/4-2/5。
已叠加“规则与 LLM 不一致且双方低置信 -> 转人工”策略，回归后两套准确率均不变
（无新增误转人工），即安全兜底零误伤。
剩余 2 个混合漏判均为语义歧义题：
- #54“东西坏了能修吗”（售后维修 vs 知识保修）
- #115“订单配送费是多少”（订单费用 vs 配送规则）

结论定稿：**规则打底（零成本）+ LLM 只兜“低置信度/难例”（触发率约 23%）+ 歧义不一致可转人工**，
既保住关键词题 99% 的日常准确率，又把语义题从 75% 拉到 99%，成本可控。
